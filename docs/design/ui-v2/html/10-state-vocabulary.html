One state vocabulary

Every lifecycle in packages/domain maps to one of nine glyphs. Shape carries meaning on its own; color reinforces it.

Needs you
An agent is blocked on your answer. Shows in the inbox and sidebar.
waiting-for-approval · waiting-for-input · interaction pending
Changing
A transition is in flight. Always shows elapsed time and the target.
provisioning · creating · starting · stopping · removing · interrupting · queued · accepted · admitting · quiesced
Working
Actively producing output.
ai-session running · ai-turn running · task-run running · process running
Healthy
Up and serving.
workspace / stack / service running · preview healthy · terminal active · project ready
Done
Finished successfully. Ready-to-review lives here.
ai-turn completed · task-run passed · operation succeeded · interaction responded
Idle
Off on purpose, or ready and waiting to be used.
stopped · inactive · absent · closed · session ready · cancelled · expired · interrupted
Degraded
Partly working. Names the subsystem that isn't.
degraded · preview unhealthy · terminal disconnected · session unavailable
Failed
Stopped with an error. Shows category, and incident ID when present.
failed · killed · timed_out · revision rejected · project invalid
Lost
DevSpace can no longer prove the state. Always paired with a recovery action.
lost — every lifecycle that has it
Wanted vs observed
Render observed. When wanted differs, append it: Starting → healthy.
Stale beats wrong
If the last authoritative read failed, dim the last state and show its age. Never a fresh Healthy.
Every bad state has a verb
Degraded, Failed and Lost always render next to their fix: retry, restart, retire or re-run.
